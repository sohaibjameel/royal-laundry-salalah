# Royal Laundry – Salalah

Concept website for Royal Laundry (الغسيل الملكي), carpet & blanket washing in Salalah, Oman.

Live: https://royal-laundry-salalah.vercel.app

- 3D hero (three.js): a dusty carpet unrolls, gets washed by bubbles, then ripples under the cursor
- English / Arabic with full RTL layout
- Before/after slider, price list, service areas, reviews
- Booking form that opens WhatsApp with the order pre-filled

Prices, reviews and hours are sample data for the preview.

Static site, no build step. Run locally with any static server, e.g. `npx serve .`
